# Android 実機テスト手順と PASS 条件（実機 Gate 準備）

方針: **実購入は実施しない**（Pro 購入・復元は別 Gate）。テストデータで行い、実データ・iOS の保存形式は変更しない。スクリーンショットは**人が目視した場合のみ**「視覚 PASS」と記録する。

## 0 実機条件
- Android 8.0（API 26）以上。**WebView／Chrome 60 以上**（Play で更新済み）。推奨は API 35／36 の実機 2 機種以上（1 台は Pixel 8 以降などの 16 KB 対応機。折りたたみ・ノッチ機があれば追加）。
- 入力する APK: CI／ローカルの Debug APK、または署名前の検証ビルド。配布・署名・Play 書込みは対象外。
- 事前: アプリをアンインストールしてから新規インストール（初回表示の確認用）。

## 1 クラウド（Emulator）で検証済み ／ 実機でのみ可能 の分離
| 項目 | Emulator で検証済み（再利用） | 実機でのみ確認 |
|---|---|---|
| APK 起動、6 競技タイル選択、下部タブ 4 種、言語切替 | 済（API35／36／16KB） | 触感・速度 |
| Safe Area（下部タブとナビバーの重なり） | 幾何計測で済（65px→0、8/8） | **目視**、ノッチ・折りたたみ・ジェスチャーナビ |
| Back A案 B0〜B6 | 済（実 OS キー） | 予測型 Back、確認ダイアログ |
| ショットクロック（初期 OFF→ON→表示） | 済 | 音・振動・長時間の精度 |
| 試合中 Back のデータ保持（B7） | §11 参照 | 実機で最終確認 |
| ネイティブ Plugin 登録、Free/Pro オーバーレイ開閉 | 済 | 実購入以外の Pro 表示 |
| プレーヤー管理、履歴／分析、バックアップ／復元、カメラ／QR、background 復帰、16KB 初回起動 | 未 | 全て実機 |

## 2 手順と PASS 条件
| # | 項目 | 手順 | PASS 条件 |
|---|---|---|---|
| D1 | 起動と初回表示 | 新規インストール → 起動 | クラッシュ・ANR なし。ホームに 6 競技タイル。起動 3 秒前後（記録） |
| D2 | Safe Area | ホームと主要画面を縦横で表示 | 下部タブがナビバー／ジェスチャーバーと重ならない。上端がステータスバーに隠れない。タップが見た目の位置に当たる（人が目視して記録） |
| D3 | 6 競技の開始と保存 | 各競技で設定→開始→数点入力→HOME 退避→プロセス kill（アプリ一覧から削除）→再起動 | 進行中試合の復帰（再開確認）またはデータ保持。6/6 |
| D4 | 試合中 Back | 試合中にシステム Back（ボタン／ジェスチャー）→再起動 | アプリ前面維持、試合データが失われない。確認ダイアログが出る場合は誤破棄しない |
| D5 | ショットクロック | 試合設定で ON → 開始 → 開始/停止・延長・リセット | 初期 OFF。ON で時計バー表示。時間の進みが実時間と ±1 秒 |
| D6 | プレーヤー管理 | 追加・編集・削除（テスト名） | 反映され、再起動後も保持 |
| D7 | 履歴／分析 | 試合後に履歴・分析を開く | 試合が記録され、数値が操作と一致 |
| D8 | バックアップ／復元 | 書出し（共有シート／SAF）→ テスト用に別データを作る → 復元 | 復元で元の内容に戻る（非破壊：復元前にバックアップを取る） |
| D9 | カメラ／QR | QR 読取（権限ダイアログ→許可／拒否の両方） | 許可で読取成功。拒否で安全なメッセージ |
| D10 | background 復帰 | 試合中に HOME→数分→復帰、画面回転 | 状態維持、タイマー異常なし |
| D11 | Free／Pro 表示 | 設定／Pro 導線を開く（購入しない） | Free／Pro 境界の表示が仕様どおり。**購入ボタンは押さない** |
| D12 | 16 KB 環境の初回起動 | 16 KB 対応機で新規インストール後すぐ起動 | 70 秒以内に WebView が表示される（F3 の再現確認）。遅延時は時刻と端末状態を記録 |
| D13 | Back A案（実機） | ホーム一覧／競技選択中／各タブ／Pro／確認ダイアログで Back | 仕様（ANDROID_BACK_DECISION_A.md）どおり。予測型 Back アニメーションと矛盾しない |

## 3 記録様式
各項目に 機種／Android／WebView 版／日時／結果（PASS／FAIL／BLOCKED）／スクリーンショット名（目視した場合のみ「視覚 OK」）を残す。FAIL は再現手順と logcat を添える。
