CuePractice Version 1.0

ビリヤードの個人練習を楽しく記録・継続するためのiPhoneアプリです。

主な機能

  • ボーラード
  • 成功率
  • 連続成功
  • 今日の練習
  • マイ記録
  • 練習履歴、カレンダー、成長の推移
  • CuePractice Proの手動バックアップ／復元

よくある質問

データはどこに保存されますか？

主要データはこのiPhone内に保存されます。Version 1.0にアカウントや自動クラウド同期はありません。

バックアップできますか？

CuePractice Proでは、設定からJSONバックアップをFiles等へ保存し、復元できます。Pro購入状態はバックアップへ含まれません。

Proはサブスクリプションですか？

いいえ。CuePractice Proは¥980の買い切りNon-Consumableです。購入の復元を利用できます。

CameraやMicrophoneを使いますか？

Version 1.0はCamera、Microphone、Location、Photosの権限を使用しません。

不具合の連絡に添えてほしい情報

  • CuePracticeのバージョン
  • iPhone機種とiOSバージョン
  • 発生した画面
  • 発生までの操作
  • 表示されたメッセージ
  • 再現性と、必要に応じたスクリーンショット
