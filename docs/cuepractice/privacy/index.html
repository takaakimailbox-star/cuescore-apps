Privacy Policy

CuePractice Version 1.0

1. 取り扱うデータ

本アプリは機能提供のため、利用者が入力または選択したPlayer名・内蔵Player Icon、練習メニュー、練習入力・結果・履歴、マイ記録、BEST、設定、バックアップ／復元データを扱います。

2. 保存と通信

  • 主要データは利用端末内に保存します。
  • CuePractice専用アカウントはありません。
  • 自動クラウド同期はありません。
  • 広告、トラッキング、Analytics、第三者分析SDKはありません。
  • Camera、Microphone、Location、Photosの権限を要求しません。
  • 将来候補の手玉速度計測はVersion 1.0に含まれず、Microphone権限も追加していません。

3. 手動バックアップ／復元

Proでは、利用者の明示操作によりJSONバックアップを作成し、Files等で選んだ保存先へ保存・復元できます。保存先やファイル共有先は利用者の操作と端末の機能により決まり、利用者がファイルを管理します。バックアップにはPlayer、練習データ、メニュー、マイ記録、設定が含まれますが、Pro購入状態は含まれません。

4. CuePractice Pro

商品情報の取得、購入、購入状態、復元、返金・取消状態はAppleのStoreKitが扱います。本アプリは検証済みの取引と現在のentitlementを用いてPro利用可否を判断します。

5. 第三者提供と安全管理

利用者が入力したアプリデータを販売または貸与しません。法令に基づく場合を除き、利用者の同意なく第三者へ提供しません。端末故障、紛失、OS不具合、アプリ削除、利用者操作等でデータが失われる可能性があるため、必要に応じて手動バックアップを利用してください。

6. 未成年者・改定

未成年者は必要に応じて保護者の管理・同意のもとで利用してください。法令、App Store要件、機能またはデータ取扱いの変更に応じ、本ポリシーを改定する場合があります。

7. お問い合わせ

CuePractice Supportをご確認いただくか、cuescore.apps@gmail.comへお問い合わせください。
