## 2. 本アプリの目的

本アプリは、ビリヤード競技における試合進行、スコア記録、プレーヤー管理、試合履歴および統計・分析の補助を目的とするアプリケーションです。

## 3. FreeとCueScore Pro

Freeでは、6競技の試合進行・保存、プレーヤー管理、最新20件の試合履歴および基本統計を利用できます。最新20件より古い記録も端末内に保持され、Freeへの切り替えによって削除されません。

CueScore Proは、一度の購入で利用できるNon-Consumableのアプリ内課金です。CueScore Proでは、保存済みの全履歴、自己ベスト、詳細分析・推移、対戦相手別の振り返り、BackupおよびRestoreを利用できます。

## 4. 購入・請求・返金

CueScore ProはAppleのIn-App Purchaseを通じて提供します。支払、請求、購入履歴および返金は、Apple AccountとAppleの仕組み・規定に従って処理されます。本アプリは独自の決済方法を提供しません。

商品価格は利用するApp StoreのstorefrontやAppleの設定に基づいて表示されます。購入を確定する前にAppleの購入確認画面で最終価格を確認してください。

## 5. 購入の復元

購入済みの資格は、本アプリの「購入を復元」からAppleの仕組みを通じて再確認できます。復元にはApp Storeへの接続や、購入時に使用したApple Accountが必要になる場合があります。
