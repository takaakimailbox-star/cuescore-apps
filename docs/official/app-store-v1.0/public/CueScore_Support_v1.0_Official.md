# CueScore Apps Support

**Version:** 1.0 Official

**Product:** CueScore Apps

CueScore Apps をご利用いただきありがとうございます。このページは、App Store から案内する公式サポートページです。

## CueScore Apps について

CueScore Apps は、ビリヤードの試合進行、スコア記録、プレーヤー管理、試合履歴、統計・分析をサポートするアプリです。

App Store v1.0 のリリース対象として、次の6競技を採用しています。

- Rotation
- 9 Ball
- 10 Ball
- JPA 9 Ball
- Straight Pool（14.1）
- Three Cushion（3C）

## よくある質問

### インターネット接続は必要ですか？

通常の試合入力、履歴確認などの主要機能は、オフラインで利用できることを v1.0 のリリース条件としています。

### データはどこに保存されますか？

Version 1.0 では、アプリデータは原則として利用端末内に保存する方針です。自動クラウド同期は Version 1.0 の対象外です。

### 機種変更やデータ保護には対応しますか？

Version 1.0 では、利用者が明示的に操作するバックアップ・復元機能をリリース対象としています。

### CSV入出力はありますか？

CSV機能は Version 1.0 の対象外です。将来のアップデート候補として管理します。

### プレーヤー写真を設定できますか？

Version 1.0 のリリース対象として、任意のプレーヤー写真設定を採用しています。

## 不具合のご連絡

不具合をご連絡いただく際は、可能な範囲で次の情報を添えてください。

- CueScore Apps のバージョン

- iOS のバージョン
- 発生した画面
- 発生までの操作手順
- 表示されたメッセージ
- 再現するかどうか
- 必要に応じてスクリーンショット

## ご意見・機能要望

操作性の改善、競技対応、分析機能などに関するご意見・ご要望を受け付けます。Version 1.0 の安定性を優先し、新機能は将来版として検討する場合があります。
