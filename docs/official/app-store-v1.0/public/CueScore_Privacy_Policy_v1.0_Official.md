# CueScore Apps Privacy Policy

**Version:** 1.0 Official  
**Effective Date:** 2026-08-09  
**Product:** CueScore Apps

## 1. はじめに

CueScore Apps（以下「本アプリ」）は、利用者のプライバシーを尊重し、利用者が本アプリに入力・登録するデータを適切に取り扱います。本ポリシーは、CueScore Apps Version 1.0 に適用されます。

## 2. 本アプリで取り扱うデータ

本アプリでは、機能提供のため、利用者が入力または選択した次のデータを端末内で取り扱う場合があります。

- プレーヤー名
- プレーヤー写真（任意）
- プレーヤーメモ（任意）
- 試合設定
- 試合中の入力内容
- スコア
- 試合履歴
- 統計・分析表示に用いる試合データ
- アプリ設定
- バックアップ・復元に用いるデータ

## 3. データの保存

Version 1.0 では、利用者が入力したアプリデータは原則として利用端末内に保存します。

Version 1.0 では、自動クラウド同期機能を提供しません。

## 4. プレーヤー写真

利用者は、任意でプレーヤー写真を設定できます。写真は本アプリ内でプレーヤーを識別・表示する目的で利用します。

Version 1.0 では、本アプリがプレーヤー写真を自動的に外部サーバーへ送信する機能は提供しません。

## 5. バックアップと復元

Version 1.0 では、利用者が明示的に操作するバックアップ・復元機能を提供する方針です。

バックアップデータの保存先および管理は、利用者が選択した保存方法や端末の機能に依存する場合があります。利用者は、バックアップデータを適切に管理してください。

## 6. アカウント情報

Version 1.0 では、本アプリを利用するための CueScore Apps 専用アカウント登録を必須としません。

本アプリは、氏名、住所、電話番号、メールアドレス、生年月日をアプリ利用の必須入力項目として要求しません。

## 7. 広告・トラッキング

Version 1.0 では、広告配信を目的としたトラッキングを行わず、広告識別子を利用したターゲティング広告を提供しない方針です。

第三者SDKや分析サービスを将来導入し、データの取り扱いが変更される場合は、本ポリシーおよび App Store Connect 上のプライバシー申告を更新します。

## 8. 第三者への提供

本アプリは、利用者が入力したアプリデータを販売または貸与しません。

法令に基づく場合を除き、利用者の同意なく、利用者が入力したデータを第三者へ提供しません。

## 9. データの安全管理

本アプリは、利用者データを適切に取り扱うよう設計・運用します。

ただし、端末の故障、紛失、OSの不具合、アプリ削除、利用者の操作その他の事由によりデータが失われる可能性があります。重要なデータについては、バックアップ機能の利用を推奨します。

## 10. 未成年者の利用

未成年者が本アプリを利用する場合は、必要に応じて保護者の管理・同意のもとで利用してください。

## 11. 本ポリシーの変更

法令、App Store の要件、本アプリの機能またはデータ取り扱いの変更に応じて、本ポリシーを改定する場合があります。

重要な変更がある場合は、本アプリまたは公式サイト等の適切な方法で案内します。

## 12. お問い合わせ

プライバシーに関するお問い合わせは、[CueScore Apps 公式サポートページ](https://takaakimailbox-star.github.io/cuescore-apps/support.html)をご確認いただくか、[cuescore.apps@gmail.com](mailto:cuescore.apps@gmail.com)へメールでお問い合わせください。
