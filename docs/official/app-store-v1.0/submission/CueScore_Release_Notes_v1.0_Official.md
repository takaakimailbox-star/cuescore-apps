## App Store運用メモ

AppleのApp Store Connectでは、初回バージョンには「What’s New in this Version」欄はありません。このRelease Notesは、CueScore Apps公式サイト／GitHub／内部リリース管理向けとして使用します。2回目以降のアップデートでは、各バージョンの変更内容をApp Storeの「What’s New」に合わせて作成します。
