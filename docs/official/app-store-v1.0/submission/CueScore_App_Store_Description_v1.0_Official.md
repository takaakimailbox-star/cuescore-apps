# CueScore Apps — App Store Description v1.0 Official

## App Name
CueScore Apps

## Subtitle
ビリヤードの試合・履歴・分析

## Promotional Text（任意）
試合を記録し、振り返り、次のプレーへ。複数競技に対応したビリヤード用スコア・履歴・分析アプリ。

## Description

CueScore Apps は、ビリヤードの試合を記録し、履歴を振り返り、プレーを分析するためのアプリです。

試合中に必要な入力をできるだけ分かりやすくまとめ、プレーヤー管理、試合履歴、統計・分析までをひとつの流れで利用できます。

【対応競技】
・Rotation
・9 Ball
・10 Ball
・JPA 9 Ball
・Straight Pool（14.1）
・Three Cushion（3C）

【主な機能】
・競技ごとの試合進行とスコア記録
・ブレイク結果の入力
・Undo
・プレーヤー管理
・メインプレーヤー設定
・アバター／プレーヤー写真
・試合履歴
・統計・分析
・Official Demo Data
・オフラインでの主要機能利用
・バックアップ／復元

CueScore Apps は、試合中の分かりやすさと、試合後の振り返りやすさを重視しています。

Version 1.0 では、安定した基本体験を優先し、自動クラウド同期およびCSV入出力は提供しません。

日々の練習、仲間との対戦、試合記録の蓄積にご利用ください。
