## Description

CueScore Apps は、ビリヤードの試合を記録し、履歴を振り返り、プレーを分析するためのアプリです。

試合中に必要な入力を分かりやすくまとめ、プレーヤー管理、試合履歴、統計・分析までをひとつの流れで利用できます。

【対応競技】
・Rotation
・9 Ball
・10 Ball
・JPA 9 Ball
・Straight Pool（14.1）
・Three Cushion（3C）

【Freeで利用できる機能】
・6競技の試合進行とスコア記録
・ブレイク結果の入力とUndo
・プレーヤー管理
・メインプレーヤー設定
・アバター／プレーヤー写真
・最新20件の試合履歴と基本統計
・オフラインでの主要機能利用

21件目以降の記録も端末内に保存され、Freeへの切り替えによって削除されることはありません。

【CueScore Pro】
CueScore Proは、一度の購入で利用できる買い切り型のアプリ内課金です。

・保存済みの全履歴
・自己ベスト
・詳細分析と推移
・対戦相手別の振り返り
・バックアップ
・復元

CueScore Apps は、試合中の分かりやすさと、試合後の振り返りやすさを重視しています。

Version 1.0 では、安定した基本体験を優先し、自動クラウド同期およびCSV入出力は提供しません。
