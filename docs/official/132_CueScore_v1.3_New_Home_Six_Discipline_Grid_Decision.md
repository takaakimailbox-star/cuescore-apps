# 132 CueScore v1.3 New Home — Six-Discipline Grid Decision

**状態: Adopted / Official。** 2026-10-24にProduct Ownerの明示承認を得て発行（Decision 045、Official Design Decision Log v2.21）。
**Scope:** Version 1.3系の**Home画面の構成**、**新規試合の種目選択の場所**、**試合設定画面の上部種目メニュー**。詳細仕様はOfficial 133。

- Decision 001〜044、Official 107〜131、Design System v2.1は**改変しない**。本Decisionは後続の判断として、第5節の範囲に限り先行記述を置換する。

## 2 背景（確認済みの事実）

- 2026-10-24、Product Ownerの実機報告で「試合設定画面で下部ホームを押しても最初のHomeへ戻らない」ことが確認された。原因は、Navigation Phase 2-6で試合設定画面の戻るボタンが削除され、下部ホームタブが試合設定表示を閉じなかったことで、最小修正をmainへ反映済み（commit `5c6b389`、既存Official 68のretap仕様への回帰修正）。
- 同日、Home再設計の案A（現行維持）／案B（Homeに6種目）の比較資料（画像、操作フロー、タップ数）がProduct Ownerへ提示された。
- 現行構成（Build 25以降）は、Homeに「新しい試合」ボタン、試合設定画面の上部に横並び6種目メニューがあり、種目選択は試合設定画面の中にある（Official 77／78、Official 86）。
- Product Ownerは**案Bを正式採用**し、6種目の配置順と試合設定画面の変更を承認した。

## 3 Decision

### D045-1 Homeの構成
HomeはCueScoreロゴ、中断試合の再開カード（中断試合が存在する場合のみ）、**6種目タイル（2列×3段）**で構成する。配置順は次のとおり固定する。

| 段 | 左 | 右 |
|---|---|---|
| 上段 | 9-Ball | 10-Ball |
| 中段 | JPA 9-Ball | Rotation |
| 下段 | 14-1 | 3 Cushion |

- 種目アイコンは採用済みの種目アイコン（`assets/icons/games/`）を使用し、**独自アイコンへ置換しない**。種目ラベルは既存の表記を変えない。
- 「新しい試合」ボタンはHomeから除き、種目タイルが新規試合の入口となる。

### D045-2 種目タイルの動作
種目タイルをタップすると、その種目が選択され、既存の試合設定へ進む。中断試合が存在する場合は、従来どおり再開カードを維持し、種目タイルをタップしたときの既存の確認（再開／新しい試合／キャンセル）を維持する。

### D045-3 試合設定画面
試合設定画面の**上部の横並び6種目メニューを削除**する。選択済み種目の大きなアイコンと種目名、プレーヤー選択、先攻／後攻、Race to／Skill Levelなど各設定、試合開始の動作は**変更しない**。左上に別の戻るボタンは**追加しない**。

### D045-4 Homeへの復帰
試合設定画面から新しいHomeへは**下部のホームタブ**で戻る。この操作は未開始の試合設定の表示を閉じるだけで、試合データ・進行中の試合を破棄しない。

### D045-5 変更しないもの
下部の4タブ（ホーム／プレーヤー／履歴／設定）、保存schema、Player Identity、QR、Backup／Restore、Free／Pro、IAP、試合の計算・記録、既存の翻訳文言は変更しない。**新しい翻訳文言を追加しない**。

### D045-6 未確定として設けないもの
B案の比較資料にあった見出し・補足文（「新しい試合／種目を選んで開始」）は、採用文言として確定していないため設けない。追加する場合は別のDecisionで定める。

### D045-7 受入条件
Official 133にAC-H1〜AC-H12を定める。

## 4 影響範囲

- 変更対象: Homeの種目タイル表示、種目タイルから試合設定への導線、試合設定画面の上部種目メニューの削除、ホームタブの復帰動作（既に反映済みの修正を仕様として固定）。
- 維持対象: 第3節D045-5のとおり。
