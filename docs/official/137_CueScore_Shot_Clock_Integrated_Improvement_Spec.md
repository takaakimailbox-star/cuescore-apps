# 137 CueScore Shot Clock — Integrated Improvement Spec

Decision 047／Official 136の仕様。Official 135（B4仕様）に**追加・上書き**する箇所のみを記す（他は135のまま）。

## 1 延長（135 §延長を上書き）

| 項目 | 仕様 |
|---|---|
| 選択肢 | ＋25／＋30／＋45／＋60秒、既定＋60 |
| 計算 | 残り＋選択秒（例: 残り8秒→33／38／53／68秒） |
| 待機中 | 延長不可（変更なし） |
| 時間切れから | 選択秒で計測を再開 |
| 取消 | 3秒以内。追加した秒数のみを引く。経過時間は戻さない。棒の基準・色も延長前へ |
| 回数 | 無制限。バッジ`×N` |
| 保存 | `cueScore.shotClock.v1`の`ext`（25/30/45/60以外は60）。クロックのスナップショットに`extSec`・`refMs`を含め、再開した試合は始めた延長秒を保つ。Build 91以前の保存値（`ext`なし）は60として読む |
| 試合設定 | ON時のみ「基本時間」の下に「延長時間」（4択、各44pt以上） |

## 2 横棒（135の配色・棒の記述を上書き）

- 基準: 開始／リセット＝基本時間、延長＝延長直後の残り時間。待機＝満タン、時間切れ＝0。
- 色はレベルで決まる。優先順位: 時間切れ → 残り5〜1秒（danger）→ 10〜6秒（warn）→ 延長使用中（ext）→ 通常（ok）。
- 色の導出（白に対する60%の濃度のティント）: 通常＝`.ball-1`(#E9C619)→#F2DD75、延長＝`.ball-6`(#008C2C)→#66BA80、注意＝`.ball-1`と`.ball-5`(#E87500)の中間(#E99E0D)→#F2C56E、残りわずか＝`.ball-5`→#F1AC66。テスト`SC47-7`がindex.htmlの実色から再計算して一致を検証する。
- 数字は中立色（主役）。0秒のみ数字と単位が赤（#D70015）。横棒は決して赤くしない。
- 遷移: 棒の幅.12s、色.3s（ゆるやか）。点滅なし。Reduce Motionで遷移停止。
- 色の識別性: 淡色のため背景トラック(#E5E5EA)とのコントラストは低い（黄は約1.1:1）。0.5pxの輪郭線を足し、数字・棒の長さ・延長バッジ・ボタンラベルで補う。

## 3 数字と単位

`.cue-sc-row`（flex、baseline）に`.cue-sc-num`と`.cue-sc-sec`。状態語は`.cue-sc-unit`（空の間は非表示）。大きい文字（130%以上）では折り返しを許す。

## 4 用語（CANDIDATE）

`shotclock.extTime`: ja 延長時間／en Extension／zh-Hans 延长时间。`shotclock.aria.extend`は`{sec}`を含む（ja「延長、{sec}秒を追加」、en "Extend, add {sec} seconds"、zh-Hans「延长，增加{sec}秒」）。メインカタログ・Official 109は変更しない。人間の独立レビュー: NOT PERFORMED。
