# CueScore Apps v1.0 — App Store Screenshots

Build 21（Version 1.0 RC）の画面を、iPhone縦向き390 × 844の表示領域で取得し、App Store Connectの6.5インチ枠へ登録できる1242 × 2688 JPEG（alphaなし）へ変換した。

## 登録順

1. `01_Home.jpg` — Home／6競技
2. `02_Player_List.jpg` — Player一覧
3. `03_Player_Detail.jpg` — Player情報／競技別通算
4. `05_History.jpg` — 試合履歴
5. `06_Match_Detail.jpg` — 試合詳細／スコア推移
6. `07_Backup.jpg` — バックアップ書き出し

`04_Rotation_Detail.jpg` は代替候補として保管するが、データ量が少なく訴求力が弱いため初回登録対象から外す。

## 保存先

- `raw/`: 取得時の画面
- `iphone-6.5/`: App Store Connect登録用JPEG

## 検証

- 全登録候補: 1242 × 2688
- format: JPEG
- alpha: なし
- App Store Connect上限: 10枚以内（登録候補6枚）
