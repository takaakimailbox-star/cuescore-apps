# PO実機確認手順（Version 1.4 / Build 89、内部TestFlight）— 6項目
前提: アプリの削除やデータ初期化は不要。TestFlightで CueScore を 1.4 (89) に更新して開く。
1. **設定**: Home で種目（例: 9-Ball）→ 試合設定の「ショットクロック」をON → 基本時間 45 を選ぶ → 「試合開始」。
2. **基本操作**: 試合画面のログ枠の下に3ボタン。「開始」→ 数字が減る → 「一時停止」で止まる → 「再開」→ 「リセット」で45に戻る（止めていれば止まったまま）。
3. **延長**: 「延長 +60」を押す（+60秒、×1表示）→ 3秒以内に「取消 −60」で元に戻る。3秒過ぎると取消は消える。
4. **独立性**: ボール・ファール・セーフティ・交代・戻るを押しても、時計は開始／停止／リセットされない。時計のボタンを押しても得点は変わらない。
5. **ロック**: 計測中に画面をロック（サイド）→ 数十秒後に復帰 → 経過した時間が引かれている。
6. **再開・OFF**: アプリを完全に終了 → 開き直す → 「中断中の試合を再開」→ 時計は「停止中」で同じ残り時間。最後に設定で時計をOFFにして新しい試合 → 画面が従来どおり（時計なし、ログが元の高さ）。
結果の返し方: 各項目 OK／NG（NGなら見えたこと）。結果が出るまで、Nativeタッチ／ロック復帰 PASS とは記録しない。
