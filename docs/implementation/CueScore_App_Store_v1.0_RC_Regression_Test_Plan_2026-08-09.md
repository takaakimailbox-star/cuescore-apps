# CueScore Apps v1.0 RC 回帰テスト計画

作成日: 2026-08-09  
実施時期: iOSネイティブ化前

## 合格条件

- Blocker / Critical不具合が0件。
- 6競技の必須フローをiPhone縦画面相当で完走。
- 保存、Undo、バックアップ/復元、データ領域分離に回帰がない。
- CSVとクラウド同期がv1.0ユーザーから見えず、利用されない。

## 6競技共通フロー

各競技で「新規試合 → 試合進行 → Undo → 試合完了 → 保存 → 履歴 → 詳細 → Analytics」を確認する。メインプレーヤーのPlayer 1初期配置、競技固有入力、Undo後のスコア・手番・履歴復元、完了結果の保存、履歴・詳細・Analyticsの一致を確認する。

- Rotation
- 9 Ball（ブレイク9のラック勝利と次ラック遷移を含む）
- 10 Ball（ブレイク10のラック勝利と次ラック遷移を含む）
- JPA 9 Ball（デッドボールを含む）
- Straight Pool 14.1
- Three Cushion 3C（イニング得点、交代、Undoを含む）

## 保存と再起動

- 試合途中で終了し、再起動後に継続状態が復元される。
- 試合完了後に終了し、再起動後も履歴・詳細・Analyticsが残る。
- プレーヤー編集、写真、メインプレーヤー設定が再起動後も残る。

## オフライン

- 初回キャッシュ済み端末をオフラインにして起動できる。
- 6競技の新規試合、進行、完了、保存、履歴閲覧が動く。
- 表示が「端末に保存」と矛盾しない。
- Privacy / Terms / Supportがキャッシュから開ける。

## バックアップ・復元

- JSONバックアップを書き出せる。
- プレーヤー、写真参照、メインプレーヤー、試合履歴が含まれる。
- 追加・統合復元で重複が増えない。
- 置換復元で対象データが一致する。
- 不正ファイルを拒否し、既存データを壊さない。
- 復元後に履歴、詳細、Analyticsが一致する。

## プレーヤー

- アバターと任意写真を登録・変更できる。
- 写真なしの既定表示が崩れない。
- メインプレーヤーを変更でき、新規試合のPlayer 1へ反映される。
- プレーヤー削除後も過去履歴の表示方針が維持される。

## 競技別プレーヤー統計4指標

- 6競技のタブ切替で、Decision 017の4指標だけが同じカード構成内で切り替わる。
- ブレイクイン率は、自分のブレイク回数を分母とし、1球以上入球かつファールなしだけを成功として集計する。
- 入球ありのスクラッチ、その他ファール、イリーガル、ブレイク失敗がブレイクイン成功へ含まれない。
- 9 Ball／10 Ballのマス割率は、既存ブレイクランアウト判定の成立ラック数 ÷ 対象完了ラック数と一致する。
- 14.1／3Cの平均得点/イニングは、総得点 ÷ 保存済み完了イニング総数と一致する。
- JPA平均イニングと3Cおすすめ持ち点は正式根拠確定まで「—」となり、誤った0を表示しない。
- 旧形式試合、現行形式試合、サンプルデータのいずれでもプレーヤー詳細が開き、保存データを書き換えない。

## Official Demo Data

- 提出版にOfficial Demo Dataが収録される。
- 作成／再読込、切替、通常へ戻る、リセット、削除が動く。
- デモ中の試合追加・編集・削除が通常データへ影響しない。
- 通常データ中の操作がデモ領域へ影響しない。
- 切替・リセット後もメインプレーヤー、写真、履歴、Analyticsが各領域内で整合する。
- Apple審査担当者がPlayers、History、Analytics、新規試合へ到達できる。

## v1.0 Later機能

- 設定およびデータ管理にCSVエクスポートが表示されない。
- 設定、履歴、データ管理にクラウド同期の操作・状態説明が表示されない。
- 過去のクラウド設定があっても、自動同期や再同期通信を開始しない。
- manifestと公開説明にクラウド同期を利用可能とする表記がない。
- JSONバックアップ・復元は引き続き利用できる。

## Official Demo Data 本番向け表示（採用済み）

現在の「開発・デモ」は本番アプリとして開発者向けに見える。通常データとの完全分離と機能名「Official Demo Data」は維持し、次を推奨する。

- セクション名: 「サンプルデータ」
- カード名: 「Official Demo Data」
- 状態: 「通常データ」／「サンプルデータ」
- 操作: 「準備する」「サンプルを見る」「通常データへ戻る」「初期状態に戻す」「削除」
- 補足: 「アプリの画面と機能を試せます。通常のデータには影響しません。」

本表示を採用・実装済み。保存領域・切替・リセットロジックは変更しない。

## 実施記録

各項目をPass / Fail / Blockedで記録し、Failには再現手順、期待結果、実際結果、端末・OS、スクリーンショット、関連コミットを添付する。
