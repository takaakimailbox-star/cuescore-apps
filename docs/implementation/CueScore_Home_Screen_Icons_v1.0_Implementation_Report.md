# CueScore Home Screen Icons v1.0 — Implementation Report

## 実装範囲

- Home上部の種目選択アイコンを正式6種目へ更新
- Home下部ナビゲーションを正式5アイコンへ更新
- 現在のCueScore App Iconを基準に、Home用CマークSVGを作成
- 選択中の種目名・種目アイコンとの連動を維持
- Service WorkerのApp Shellへ全SVGを追加

## 種目アイコン

| 種目 | 表示 | 輪郭色 |
| --- | --- | --- |
| Rotation | R | `#9A3F0A` |
| 9-Ball | -9- | `#F4B400` |
| 10-Ball | -10- | `#0057B8` |
| 14-1 | 14-1 | `#0A7D2C` |
| JPA 9-Ball | JPA / 9 | `#F4B400` |
| 3 Cushion | 3C | `#6F6F6F` |

6種目は横一列で表示し、狭い画面では横スクロールできます。選択中は文字を濃くし、短い下線と控えめな輪郭強調で示します。

## 下部ナビゲーション

- ホーム：CueScore公式App Iconを基準にしたCマーク
- プレーヤー：人物アウトライン
- 履歴：円形VS
- 分析：4本バー
- 設定：歯車

ラベルは日本語で統一し、選択中のみ黒・太字、未選択はグレーとしています。

## 既存機能への影響

- 種目選択、選択保存、Homeカードへの反映処理は既存ロジックを再利用
- New Match、プレーヤー選択、Race設定、試合開始処理は変更なし
- 下部ナビゲーションの遷移処理は変更なし
- Game画面では従来どおり下部ナビゲーションを表示しない

## 表示確認

- 390 × 844：横一列・横スクロール・下部Safe Areaを確認
- 430 × 932：6種目すべての表示、下部ナビゲーションを確認
- 3 Cushion選択：選択状態、Homeカード名、SVG資産の連動を確認
