# PO実機確認（1回で完了）— Version 1.4 / Build 90（内部TestFlight）
前提: TestFlight で CueScore を 1.4 (90) に更新して開く。アプリの削除・データ初期化は不要。Build 89 の実機テストを先にやる必要はありません（この確認にまとめています）。
## 準備（30秒）
1. Home で **9-Ball** を選ぶ → 試合設定で ①「ショットクロック」をON（45秒） ②「操作画面の比較（試験）」をON → 「試合開始」。
2. 試合画面の右上「開始時刻 hh:mm・**新**」が比較スイッチです。**タップするたびに 新（改善案）⇄ 旧（現行）** が切り替わります（試合の状態はそのまま）。
## 確認項目（OK／NG だけ返信）
- **A ショットクロック**: 「開始」→ 数字が減る → 「一時停止」→「再開」→「リセット」→「延長+60」→3秒以内に「取消 −60」。
- **B ロック・復帰**: 計測中に画面をロック（サイド）→ 数十秒後に復帰 → 経過分が引かれている。アプリを終了 → 開き直して「中断中の試合を再開」→ 時計は停止状態。
- **C Race to**: 9-Ball で、ファールの後も「Race to 5」の1行だけ。手球フリーは名前の上の小さなバッジ。
- **D 新／旧の見た目**: 右上をタップして切り替え、**どちらが見やすいか**（ボール・操作ボタン・手番カード）。
- **E ボール入力**: 新と旧で、**ボールを押しやすいのはどちらか／隣のボールを押し間違えたか**。
- **F 戻る・交代・ファール**: 新では「戻る」が灰色で右に離れています。**押し間違えにくいか**。
- **G 動き**: 新で、スコアの更新・ログの追加・手番切替の動きが**自然か（邪魔でないか）**。（iPhoneの「視差効果を減らす」をONにすると動きが消えます）
## 返信の例
「A OK／B OK／C OK／D 新／E 新（押し間違えなし）／F 新／G 自然」
## 注意
- 比較スイッチが出るのは 9-Ball／10-Ball のみ。他の種目は従来どおり。
- 翻訳（試験UI・ショットクロックの20語）は暫定です。
- 実機の結果が出るまで、この機能は未採用・未検証として扱います。
