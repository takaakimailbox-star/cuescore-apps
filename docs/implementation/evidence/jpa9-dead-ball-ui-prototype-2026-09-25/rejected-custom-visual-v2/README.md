# Rejected Prototype — Custom Dead Visual

These images preserve the intermediate 2026-09-26 prototype for decision history only.

Product Owner rejected the newly designed `opacity: 0.46`, `saturate(0.55)`, and `brightness(0.82)` Dead visual. These images are not the adopted UI and must not be used as implementation guidance.

The corrected direction is to preserve the released product's existing normal JPA Dead ball presentation exactly and reuse that same `state="used"` presentation for break-scratch and other rule-confirmed Dead balls.
