## 3. 開始条件・disabled（最重要）
- 開始条件は不変。`final-ui-build18.js` の `start.disabled = players.length<2 || !selected(1) || !selected(2) || 同一` が唯一の決定元。
- HTML の `disabled` 属性を `aria-disabled` へ置き換えていない（無効ボタンのタップ検出のためだけの変更はしない）。新規スクリプトは `disabled` を一切書かない（静的テストで固定）。
- 無効の理由は、フッターの理由行（不足条件に応じて 3 種）で示す。理由行はタップすると既存のプレーヤー選択ボタンを押す（不足カードへの誘導。新しい画面遷移・Dialog はなし）。

## 4. 数値メニューの仕組み（既存ロジックを変えない）
- メニューは、既存の Race to シートの**表示を差し替える**だけ。行を選ぶと、既存シートの同じボタン（`data-race-value`）をクリックするため、検証・適用・「その他」の範囲（9-Ball／10-Ball／3 Cushion は 1〜100、14-1／Rotation は 1〜1000）は従来のコードが実行する。
- 値の一覧はスクリプトに持たない（既存シートから取得）。時計は既存定数 `BASES`／`EXTS` を使用。
- 既存の AC-S3（MutationObserver 登録数・テキスト書込み）を守るため、DOM 監視は使わず、明示的なユーザー操作イベント後の 2 フレーム＋遅延更新（`final-ui-build18.js` の `refreshSoon` と同方式）で状態を同期する。
