# PO実機確認（1回で完了）— Version 1.4 / Build 91（案A 試験実装・内部TestFlight）
前提: TestFlight で CueScore を 1.4 (91) に更新して開く。アプリの削除・データ初期化は不要。案Aの見た目は**内部評価用の候補**で、公開用デザインとして確定したものではありません。
## 準備（30秒）
Home で 9-Ball を選ぶ → 試合設定で「ショットクロック」をON（45秒）。比較したいときだけ「操作画面の比較（試験）」もON → 「試合開始」。試合画面右上の「開始時刻 hh:mm・新／旧」をタップすると P1 の 新⇄旧 を切り替えられます（時計は止まりません）。
## 確認項目（OK／NG だけ返信）
- **1 残り時間**: 試合画面を見て、**残り時間（大きな数字）が真っ先に目に入るか**。
- **2 リセット**: 太い枠の「リセット」がすぐ見つかるか。
- **3 延長**: 「延長 +60」が見つけやすく、押しやすいか。最後の10秒で色が付くのは分かりやすいか。
- **4 開始／一時停止**: 白地の「一時停止／開始／再開」が**押しにくくないか**（幅は以前の約7割、高さ48pt）。押し間違い・押し損ねがあったか。
- **5 ボールと時計**: ボール入力と時計操作を交互にして使いやすいか。ボールを押しても時計が変化しないこと。
- **6 P1 新／旧**: 右上をタップして切り替え、**どちらが使いやすいか**（時計はどちらでも同じ見た目・動作で、切り替えても止まらない／戻らない）。
- **7 手球フリー**: ファール後などで「手球フリー」の文字・バッジが**どこにも出ない**こと（Race to は「Race to 5」の1行）。
- **8 ロック・復帰**: 計測中に画面をロック → 復帰で経過分が引かれている。アプリ終了 → 「中断中の試合を再開」で時計は停止状態。
## 返信の例
「1 OK／2 OK／3 OK／4 やや押しにくい／5 OK／6 新／7 OK／8 OK」
## 注意
- 比較スイッチは 9-Ball／10-Ball のみ。時計の仕様（45秒、延長無制限、3秒取消、自動ファールなし、ボール入力と独立）は変わっていません。
- 翻訳（時計・試験UI）は暫定です。実機結果が出るまで本機能は未採用・未検証として扱います。
