CUESNAPI PRIVACY POLICY

プライバシー

Version 1.0 · 2026年9月7日制定

取り扱うデータ

CueSnapiは、利用者が選択または撮影したビリヤードテーブルの写真、ボール配置、配置名・メモ、アプリ設定を機能提供のために扱います。

写真へのアクセス

写真ライブラリとカメラへのアクセスは、利用者が選んだ写真の読み込みまたは撮影のためにのみ使用します。写真は端末上で解析し、CueSnapiが自動的に外部サーバーへ送信する機能はありません。

保存

Version 1.0の配置データと設定は原則として利用端末内に保存します。専用アカウント登録や自動クラウド同期は提供しません。

購入情報

CueSnapi Proの購入・復元はAppleのStoreKitとApp Storeにより処理されます。CueSnapiがクレジットカード番号などの支払情報を取得・保存することはありません。

広告・トラッキング

Version 1.0では広告配信を目的としたトラッキングを行いません。利用者のアプリデータを販売または貸与しません。

データの削除

保存した配置はアプリ内で削除できます。アプリを削除すると、端末内のアプリデータも削除される場合があります。

お問い合わせ

プライバシーに関するお問い合わせは cuescore.apps@gmail.com へお送りください。
