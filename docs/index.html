CueScore for iPhone

試合を記録する。
振り返る。
次の一球につなげる。

CueScoreは、ビリヤードの試合スコアとプレーヤー成績を、シンプルに記録・確認できるiPhoneアプリです。

App Store 公開予定サポート

iPhone / Version 1.0

Built for the match

スコアだけで終わらない。

01

記録

試合中の入力を、できるだけ迷わず。

各ゲームに合わせたスコア入力で、試合結果をそのまま履歴へ残します。

02

振り返り

試合ごとの結果を、あとからすぐ確認。

相手、種目、スコア、試合詳細を履歴からたどれます。

03

成績

自分のプレーを、数字で見る。

プレーヤー情報から成績・試合・分析を確認できます。

Match

試合の流れに集中できるスコア入力

種目を選び、プレーヤーを決めて、そのまま試合へ。試合中の操作をできるだけシンプルにまとめています。

History

あとから探しやすい試合履歴

全体履歴、種目別、対戦相手別から試合を振り返れます。

Player

プレーヤーごとの成績をひとつの場所に

成績・試合・分析をプレーヤー単位で確認できます。

Privacy

記録を安心して使えるように。

Version 1.0のアプリデータは原則として利用端末内に保存され、自動クラウド同期は提供しません。詳しい取り扱いは正式なポリシーをご確認ください。
